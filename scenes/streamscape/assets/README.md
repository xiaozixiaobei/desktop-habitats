# Streamscape references

Red mahseer (Tor tambroides / the ornamental “red kelah” appearance) is represented by an original procedural model, not a downloaded fish photograph. The large overlapping scales, thick lower lip, barbels and forked tail are based on these references:

- [FishBase — Tor tambroides](https://www.fishbase.se/Fieldguide/FieldGuideSummary.php?c_code=156&genusname=Tor&speciesname=tambroides): morphology; gravel/cobble pools and runs; juveniles near rapids.
- [Jaafar et al. (2021), Biology 10(4), 286](https://pmc.ncbi.nlm.nih.gov/articles/PMC8065745/): Tor morphology and the uncertainty of species identification in the group.
- [Pierre Wildlife — Tor tambroides](https://www.pierrewildlife.com/searchspecies/tortambroides/): photographic reference for proportions and scale appearance.

References were consulted on 2026-09-23; their photographs are not redistributed. The rose-red body, dark overlapping scale margins and crimson fins follow the user-supplied ornamental-fish photograph. Its image is used only as a visual reference and is not redistributed. This appearance is not an identification claim for every fish sold under the common name.

Sand and rock textures reuse the bundled Riverscape assets under `../../riverscape/assets/` (Poly Haven CC0; see the root README credits). Geometry, scale patterns, fin rays, algae and current particles are generated locally. The scene has no runtime network dependencies.
